# SwasthyaSetu

### Gaon Se Sahi Ilaaj Tak

SwasthyaSetu is a bilingual healthcare navigation prototype that connects rural patients with health workers, doctors, hospitals, referrals, appointments, and transport support.

## Features

- English and Hindi interface
- Role-based login for patients, health workers, and hospitals
- Healthcare category finder
- Hospital recommendations
- Voice input simulation
- Referral tracking
- Appointment and transport details
- Digital health records
- Emergency help page
- Responsive mobile-first design
- LocalStorage-based demo data

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Web Speech API
- LocalStorage
